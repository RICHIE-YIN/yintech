# YinTech Service Logo Mark Prompts

Use these prompts for the small square service logo marks on the homepage Phase 1 cards and the full Services page. These should be simple icon/logo marks that sit inside the existing little rounded square.

## Common Style Prefix

Create a 1024x1024 square service logo mark for YinTech Solutions on a transparent background. Make one centered geometric symbol only, no text, no letters, no surrounding card, no UI panel. Use a minimal premium enterprise technology style with clean vector-like edges, deep graphite base shapes, electric blue #2F7DF6 accents, and at most one tiny cyan #42D6D3 signal detail. The mark must remain readable at 36px, use strong silhouette, balanced negative space, and feel like part of one consistent service icon family.

## Negative Prompt

Readable words, letters, fake brand names, screenshots, UI panels, browser chrome, people, robots, humanoid AI, brain graphics, neon cyberpunk, cryptocurrency symbols, purple gradients, pink gradients, oversized glow, stock office scene, mascot, emoji, watermark, complex detailed illustration.
